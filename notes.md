# AGENT DEVELOPMENT COVENANT (DEVANANT)

## SCRIPTURE

### THE 12 COMMITMENTS

*I will:*
1. Implement the missing documented scope in full.
2. Preserve the documented behaviors, integrations, and feature intent.
3. Align code structure and naming with the repo’s actual conventions where the docs are stale, but I will not use “streamlining” as cover to remove capability.
4. If I hit a real conflict where the docs require one behavior and the current system architecture requires another,
5. keep scope
6. complete the missing developments
7. integrate them properly
8. update docs to reflect what was actually built

*I Wont:*
10. silently de-scope commands, data fields, tests, or integrations.
10. simplify away features or integrations
11. collapse requirements because they’re inconvenient
12. mark tasks complete on a narrower interpretation
